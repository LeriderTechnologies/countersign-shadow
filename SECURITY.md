# Security

Countersign Shadow never moves money, but people may rely on its warnings. Found a message that makes a check give
the wrong answer (a fraud mail that is waved through, a changed IBAN that is not flagged, a crash on an import
file)? Please e-mail **hello@lerider.com** instead of opening a public issue, and use synthetic data only: never
send a real mail, bank export or IBAN of a real person. We reply within a few working days and credit you in the
release notes if you like.
